🚀 Deploy to GitHub Pages

Your portfolio will be live at https://yourusername.github.io/portfolio — completely free, forever.

  1. Download your portfolio file
    Click "Download HTML" to save index.html to your computer.
  2. Create a new GitHub repository
    Go to github.com/new → Name it portfolio (or your username) → Make it Public → Click "Create repository"
  3. Upload your file
    Click "uploading an existing file" → Drag your index.html → Commit changes.
  4. Enable GitHub Pages
    Go to repo → Settings → Pages (left sidebar) → Source: Deploy from a branch → Branch: main → Save.
  5. Your site is live! 🎉
    Wait ~2 minutes, then visit:
    https://YOUR-USERNAME.github.io/portfolio
    Share this link on your resume and LinkedIn!
💡 Pro tip: Name your repo exactly yourusername.github.io to get the cleanest URL — no subfolder needed!
